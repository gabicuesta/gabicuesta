#### How I think about AI in engineering

- **Evals before opinions.** If you can't measure it, you can't ship it.
- **Cost and latency are product features**, not afterthoughts.
- **Agents augment teams.** The goal is better engineers, not fewer standards.
- **Boring architecture, sharp edges only where they pay off.**
